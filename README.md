# lab-02-
## Цель проекта

Цель проекта — создать небольшую воспроизводимую проектную капсулу для лабораторной работы № 2 по информатике и основам программирования.

Проект демонстрирует принципы цифровой организации материалов: понятную структуру папок, содержательные имена файлов, хранение учебных данных отдельно от notebook, описание проекта в README и фиксацию изменений в журнале версий.

Материалы репозитория позволяют другому пользователю быстро понять назначение файлов, найти notebook, данные и документацию, а также проверить, что в проекте не используются персональные данные, пароли, токены и другие конфиденциальные сведения.
## Состав файлов

- `lab1.ipynb` — notebook с материалами и результатами лабораторной работы № 1.
- `data/sample_text.txt` — безопасный учебный текстовый файл.
- `data/metadata.tsv` — таблица с описанием основных файлов и относительными путями к ним.
- `docs/version_log.md` — журнал версий и осмысленных изменений проекта.
- `docs/peer_review.md` — результат peer review, замечание и выполненное исправление.
